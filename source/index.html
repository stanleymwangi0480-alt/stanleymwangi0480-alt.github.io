Project Summary

Mystique Compass is a numerology, astrology, psychomatrix, Loshu grid, and Chinese zodiac profile generator built with React, TypeScript, and Vite. It generates detailed cosmic profiles including numerology readings, psychomatrix charts, Loshu grid analysis, Chinese zodiac readings, astrology profiles, cosmic fate maps, personal year predictions, and more.

Tech Stack: React 18, TypeScript, Vite, shadcn/ui components, CSS animations. Backend: Express.js API server. Analytics: Cloudflare Workers + KV storage. PWA: Service Worker with install support.

Analytics: The app tracks installs, sessions, and shares via a Cloudflare Worker at https://mystique-analytics.sksalemking.workers.dev. The dashboard at /stats/ shows anonymous usage data.
